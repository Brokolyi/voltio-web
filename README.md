# Voltio

Estaciones de carga para vehículos eléctricos en toda Colombia — ciudades, pueblos y carreteras, con el tipo de conector y las marcas compatibles.

## Usar Voltio

- **Como app web (PWA)**: abre la app en el navegador de tu celular y usa "Agregar a pantalla de inicio" (Android/Chrome) o "Compartir → Agregar a inicio" (iPhone/Safari) para instalarla como si fuera una app.
- **Como app Android (.apk)**: descarga el instalador desde la sección [Releases](../../releases) de este repositorio e instálalo directamente (Android puede pedirte permitir "instalar apps de orígenes desconocidos" la primera vez).

No se recolecta información personal. Ver la [política de privacidad](https://brokolyi.github.io/voltio-privacy/).
